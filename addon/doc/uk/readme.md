# Item Order Announcer (Оголошення порядку елемента)

* **Автор:** balaraz <balaraz@tuta.io>
* **Сумісність з NVDA:** від 2024.1 по 2026
* **Завантаження:** [Репозиторій GitHub][repo], [випуски][rels]

Цей додаток для програми зчитування з екрана NVDA швидко оголошує порядок, загальну кількість елементів та рівень вкладеності поточного об'єкта навігатора (який за замовчуванням слідує за фокусом, наприклад, елементів списків, вузлів деревоподібних списків або пунктів меню).

## Можливості

* **Миттєве оголошення порядку:** Оголошує номер поточного елемента та загальну кількість елементів у групі (наприклад, «3 з 10»).
* **Швидке визначення для MSAA:** Миттєво визначає порядок елементів для класичних MSAA-програм (наприклад, wxWidgets або Poedit) без фонового розрахунку.
* **Оголошення рівня:** Автоматично додає ієрархічний рівень вкладеності, якщо він доступний (наприклад, «3 з 10, рівень 2»).
* **Приблизне визначення порядку з фільтрацією:** Дозволяє оцінити порядок елемента шляхом підрахунку сусідніх об'єктів з можливістю вибору фільтрації за роллю або підрахунку всіх сусідніх об'єктів.
* **Налаштовувані комбінації клавіш:** Усі комбінації клавіш можна змінити в діалозі «Жести вводу» NVDA.

## Комбінації клавіш

| Гаряча клавіша | Опис |
| --- | --- |
| `NVDA+I` | Оголошує номер, загальну кількість елементів та рівень вкладеності поточного об'єкта навігатора. |
| `NVDA+Control+I` | Відкриває меню вибору фільтра («За роллю» або «Усі сусідні об'єкти») та приблизно визначає позицію елемента на основі сусідніх об'єктів. |

> **Примітка:** Ви можете налаштувати або змінити ці комбінації клавіш у будь-який час у меню **NVDA -> Параметри -> Жести вводу -> Об'єктна навігація**.

## Як це працює

* **Точна позиція:**
  1. Додаток отримує поточний об'єкт навігатора.
  2. Перевіряє вбудовані метадані позиції елемента та його групи, включаючи швидке пряме визначення позиції для класичних елементів MSAA.
  3. Якщо інформація про позицію доступна, NVDA оголошує:
     - `<index> з <total>`
     - Якщо існує рівень вкладеності: `, рівень <level>`
  4. Якщо метадані позиції відсутні, NVDA повідомляє «Порядок недоступний».

* **Приблизна позиція:**
  1. Якщо точні метадані позиції недоступні, виклик комбінації клавіш відкриває випливаюче меню для вибору стратегії фільтрації:
     - **За роллю:** підраховує лише ті сусідні об'єкти, які мають таку ж роль доступності, як і поточний елемент.
     - **Усі сусідні об'єкти:** підраховує всі сусідні об'єкти в контейнері незалежно від їхньої ролі.
  2. Додаток аналізує батьківський контейнер поточного об'єкта та розраховує позицію асинхронно у фоновому потоці.
  3. У разі успіху NVDA оголошує: `Приблизно <index> з <total>`.
  4. Якщо позицію не вдалося визначити, NVDA повідомляє «Не вдалося визначити порядок».
  5. Виклик нового розрахунку або зміна фокуса автоматично скасовує будь-яке активне фонове обчислення. Оголошення фокуса приглушується лише при виборі пункту меню (і відбувається як звичайно при закритті меню клавішею Escape).

## Журнал змін

### Версія 2.1
- Змінено стандартну комбінацію клавіш для приблизного визначення порядку на `NVDA+Control+I`, щоб уникнути конфлікту зі вбудованими жестами NVDA.

### Версія 2.0
- Додано інтерактивне випливаюче меню вибору фільтра («За роллю» або «Усі сусідні об'єкти») при визначенні порядку через `NVDA+Shift+I`.
- Додано оптимізоване швидке O(1) визначення порядку для класичних MSAA-елементів (наприклад, wxWidgets, Poedit) напряму через `NVDA+I`.
- Автоматичне скасування поточних фонових розрахунків при виклику нової команди визначення порядку.
- Приглушення зайвих оголошень фокусу лише при виборі пункту з меню фільтра (при закритті меню клавішею Escape фокус оголошується як звичайно).
- Оновлено українську локалізацію та документацію.

### Версія 1.1
- Прибрано слово «Елемент» із повідомлень оголошення для лаконічнішого виводу (наприклад, «3 з 10» замість «Елемент 3 з 10»).
- Оновлено мінімальну версію NVDA до 2024.1 через вимоги синтаксису Python 3.10+ (старіші версії NVDA використовують Python 3.7, тоді як NVDA 2024.1 оновлено до Python 3.11).
- Переведено резервне приблизне визначення порядку у фоновий потік із періодичним звуковим індикатором прогресу (звуковий сигнал), щоб уникнути зависання NVDA під час обходу великих контейнерів.
- Додано затримку звукового індикатора прогресу, щоб запобігти зайвим звуковим сигналам на швидких списках.
- Автоматичне скасування фонового розрахунку порядку елемента при переході фокуса на інший об'єкт.
- Оновлено українську локалізацію та документацію.

### Версія 1.0
* Додано скрипт для оголошення порядку елемента у фокусі, загальної кількості та рівня вкладеності.
* Додано резервний скрипт для приблизного визначення порядку та загальної кількості елементів на основі сусідніх об'єктів, коли точні метадані позиції недоступні.
* Призначено стандартні комбінації клавіш (`NVDA+I` та `NVDA+Shift+I`) для цих скриптів.
